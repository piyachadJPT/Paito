# ทดลองใช้จริง 19–20 ธ.ค. 2569

จุดประสงค์คือทดสอบแอปในสภาพจริงก่อนทริปปีใหม่ (31 ธ.ค.) ให้เหลือเวลาแก้บั๊กราว 10 วัน ทดสอบตอนขับรถออกไปข้างนอกจริง ไม่ใช้นาฬิกาจำลอง

## เตรียมตัว (ภายใน 18 ธ.ค.)

- [ ] Deploy เวอร์ชันล่าสุดแล้ว และในแอปบน Home Screen เวอร์ชัน build ตรงกับ commit ล่าสุด
- [ ] สร้างทริปจริงสั้น ๆ 2 วัน (19–20 ธ.ค.) ใส่สถานที่ที่จะไปจริงวันละ 3–5 แห่ง ให้มีครบทุกแบบ:
  - มีร้านอาหาร (food) และจุดแวะพัก (rest) อย่างละ 1 แห่ง
  - มีสถานที่ 1 แห่งที่ล็อกเวลาถึง เช่น ร้านที่จองโต๊ะไว้
  - มีสถานที่ที่วางลิงก์จาก Google Maps แบบสั้น (`maps.app.goo.gl`), แบบมีพิกัด และแบบพิมพ์ชื่อ อย่างละแห่ง
  - กรอกโน้ตทริป มีเบอร์โทรอย่างน้อย 1 เบอร์
- [ ] ตั้งทริปนี้เป็นทริปที่ใช้อยู่ และนาฬิกาจำลองต้องปิดอยู่ (ไม่มีแถบ "นาฬิกาจำลอง")
- [ ] เปิดแอปตอนมีเน็ตอย่างน้อย 1 ครั้งก่อนออกจากบ้าน เพื่อให้แอปเก็บไฟล์ไว้ใช้ออฟไลน์
- [ ] ถ้าเพิ่งได้ผลการทดสอบ AC-12 (ปุ่มนำทาง) ให้ส่งผลมาแก้ก่อนวันทดลอง

## ระหว่างวัน: สิ่งที่ต้องลอง

**การใช้งานหลัก**
- [ ] ใช้แค่หน้า "ตอนนี้" ทั้งวัน: กด "ถึงแล้ว" ทุกครั้งที่ไปถึง และกด "เสร็จ · นำทางไปต่อ" ทุกครั้งที่ออก
- [ ] ระหว่างขับ ให้คนนั่งข้าง ๆ ลองอ่านหน้าจอ ดูว่าเห็น "ต้องออกในอีก" และ "ถึงประมาณ" ได้ในแวบเดียวหรือไม่
- [ ] ตั้งใจเที่ยวเกินเวลาที่ใดที่หนึ่ง แล้วลองทั้ง "ออกตามแผน" และ "เลื่อนแผนที่เหลือ"
- [ ] ตั้งใจข้ามสถานที่ 1 แห่ง
- [ ] เพิ่มสถานที่ที่ไม่ได้วางแผนไว้ระหว่างทาง 1 แห่ง เช่นปั๊มน้ำมันหรือคาเฟ่
- [ ] เปิดข้อมูลสำคัญแล้วกดโทรจากเบอร์ในโน้ต

**การนำทาง**
- [ ] กดนำทางทุกครั้งที่ออกจากสถานที่ จดว่าเปิดแอป Google Maps ได้ทุกครั้งไหม และลิงก์แต่ละแบบ (สั้น / พิกัด / ชื่อ) ไปถูกที่ไหม
- [ ] กลับจาก Google Maps เข้าแอป "ไปต่อ" แล้วหน้าจอยังอยู่ที่เดิม สถานะที่กดไว้ยังอยู่

**การเตือน**
- [ ] แถบเตือน "อีก 15 นาทีต้องออก…" ขึ้นตรงเวลา หรือขึ้นทันทีเมื่อกลับเข้าแอป
- [ ] การเตือนพอดีหรือถี่เกินไป จดไว้ว่าอยากให้เปลี่ยนตรงไหน

**สัญญาณอ่อนและออฟไลน์**
- [ ] จดจุดที่ไม่มีสัญญาณ เช่นบนดอยหรือในวัด แล้วกดสถานะตรงนั้น ป้ายต้องเป็น "ออฟไลน์ · รอส่ง n"
- [ ] พอมีสัญญาณ ป้ายกลับเป็น "ออนไลน์" เองโดยไม่ต้องกดอะไร
- [ ] ถ้าเห็น "ส่งไม่สำเร็จ" ให้ถ่ายหน้าจอหน้าตั้งค่า → sync ไว้ก่อน อย่าเพิ่งกด "ทิ้ง"

**ข้ามเที่ยงคืน (คืนวันที่ 19)**
- [ ] ถ้ากลับที่พักหลังเที่ยงคืน หน้า "ตอนนี้" ต้องยังเป็นวันที่ 1
- [ ] เช้าวันที่ 20 เปิดแอป ต้องเปลี่ยนเป็นวันที่ 2 เอง และบอกเวลาออกของวันนี้

**ตัวเครื่อง**
- [ ] แบตเตอรี่: จดเปอร์เซ็นต์ตอนออกจากบ้านและตอนกลับ เทียบกับวันปกติ
- [ ] อ่านจอกลางแดดได้ไหม
- [ ] ปัดปิดแอปทิ้งกลางวันแล้วเปิดใหม่ ต้องยังล็อกอินอยู่และเห็นข้อมูลล่าสุด
