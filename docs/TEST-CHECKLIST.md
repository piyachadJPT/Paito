# เช็กลิสต์ทดสอบบน iPhone (AC-01 … AC-13)

อ้างอิงเกณฑ์จาก SPEC ข้อ 14.2 ทดสอบทีละข้อแล้วติ๊ก ถ้าไม่ผ่านให้แจ้งด้วยแบบฟอร์ม "แจ้งบั๊กหลังทดสอบ" ใน `docs/PROMPTS.md`

## ก่อนเริ่ม

- [ ] Deploy เวอร์ชันล่าสุดแล้ว เปิด `https://<โดเมน>.vercel.app` ใน Safari ได้
- [ ] ติดตั้งลง Home Screen: Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" → เปิดจากไอคอน "ไปต่อ" ต้องไม่มีแถบ URL
- [ ] ตรวจว่าเป็นเวอร์ชันล่าสุด: ตั้งค่า → แผงนักพัฒนา → "เวอร์ชัน build" ต้องตรงกับ commit ล่าสุด
- [ ] **ใช้ทริปทดสอบแยก** ห้ามทดสอบบนทริปจริง ให้นำเข้า `docs/seed-trip.json` เป็นทริปใหม่ แล้วลบทิ้งเมื่อทดสอบเสร็จ (ตั้งค่า → ลบทริป)

> แอปบน Home Screen กับ Safari เก็บข้อมูลแยกกัน ต้องล็อกอินแยกกัน และนาฬิกาจำลองที่ตั้งใน Safari ไม่มีผลกับแอปบน Home Screen

## วิธีใช้นาฬิกาจำลอง

นาฬิกาจำลองเปลี่ยนเฉพาะเวลาที่แอปเห็น เวลาจะเดินต่อเองจากเวลาที่ตั้ง และจำไว้ในเครื่องจนกว่าจะรีเซ็ต ระหว่างที่เปิดใช้ ทุกหน้าจะมีแถบ "นาฬิกาจำลอง" ค้างอยู่ด้านบน

**วิธีที่ 1: ใส่ในลิงก์ (ใช้ได้ใน Safari)**
- `https://<โดเมน>/?now=2026-12-31T07:30` ตั้งเวลา (เป็นเวลาไทย)
- `https://<โดเมน>/?now=off` ยกเลิกนาฬิกาจำลอง

**วิธีที่ 2: แผงนักพัฒนา (ใช้ได้ทั้ง Safari และแอปบน Home Screen)**
1. เปิด `https://<โดเมน>/settings?dev=1` ครั้งเดียว แผงนี้จะจำไว้ในเครื่อง
2. ตั้งค่า → นักพัฒนา → เลือกวันที่และเวลา → "ตั้งเวลาจำลอง"
3. ใช้ปุ่ม "+15 นาที" / "+1 ชม." เพื่อเลื่อนเวลา และ "รีเซ็ต" เพื่อกลับเป็นเวลาจริง

ในแอปบน Home Screen พิมพ์ลิงก์ไม่ได้ จึงมีสองทาง: ทดสอบข้อที่ต้องใช้นาฬิกาจำลอง (AC-04, 06, 07, 08) ใน Safari ซึ่งใช้ logic ชุดเดียวกัน หรือเปิด `?dev=1` ใน Safari ก่อนกด "เพิ่มไปยังหน้าจอโฮม"

**เวลาตามแผนของทริปทดสอบ (Day 1 · 31 ธ.ค.) ที่ใช้ในข้อด้านล่าง**

| สถานที่ | ถึง | ออก |

## AC-01 สร้างทริปและนำเข้า
- [ ] ตั้งค่า → ทริป → สร้างทริปใหม่ จากวันที่ 1–3 ของเดือนใดก็ได้ → หน้าแผนเที่ยวมี D1, D2, D3 ครบ ทุกวันมีจุดเริ่มต้น
- [ ] ตั้งค่า → นำเข้าไฟล์ → เลือก `seed-trip.json` (ส่งไฟล์เข้า iPhone ผ่าน AirDrop หรือ iCloud Drive ก่อน) → ได้ 4 วัน, Day 1 ออก 08:00 น. และถึงที่พัก 00:45 น.
- [ ] ลบทริปที่สร้างในข้อแรกทิ้ง

## AC-02 แก้แผนแล้วเวลาคำนวณใหม่
ทำในหน้าแผนเที่ยว Day 1
- [ ] แตะ "วัดพระธาตุลำปางหลวง" → กด "+15 นาที" 2 ครั้ง (90 → 120 นาที) → บันทึก → พิพิธภัณฑ์ฯ เปลี่ยนเป็นถึง 11:50, Lampang Festival ยังเป็น 19:00 และมีป้าย "จะถึงช้ากว่าเวลาที่ล็อก 10 นาที"
- [ ] กด "ย้อนกลับ" ใน toast → ทุกอย่างกลับเป็นค่าเดิม
- [ ] เพิ่มสถานที่ → จุดใหม่ต่อจากสถานที่สุดท้ายก่อนที่พัก และขึ้นป้าย "ยังไม่กรอกเวลาขับ"
- [ ] สลับลำดับด้วยปุ่ม "ขึ้น" / "ลง" → ขึ้นป้าย "ตรวจเวลาขับ"
- [ ] "ย้ายวัน" → เลือก Day 2 → สถานที่หายจาก Day 1 และไปอยู่ใน Day 2 เวลาของทั้งสองวันคำนวณใหม่
- [ ] "ลบสถานที่นี้" (ต้องมีถามยืนยัน) → เวลาของจุดถัดไปเลื่อนเข้ามา
- [ ] ตลอดข้อนี้ Lampang Festival ต้องยังเป็น 19:00 เสมอ

## AC-03 เปลี่ยนสถานะและย้อนกลับ
- [ ] แตะสถานที่ → "ถึงแล้ว" → ชิปเปลี่ยนเป็น "กำลังเที่ยว" และมี toast "บันทึกแล้ว · ย้อนกลับ" ค้าง 8 วินาที
- [ ] "เสร็จ" → ขึ้น "เสร็จแล้ว" · "ย้อนสถานะ" → กลับเป็น "กำลังเที่ยว"
- [ ] "ข้าม" → ชื่อถูกขีดฆ่าและสีจางลง · "ย้อนสถานะ" → กลับเป็น "ยังไม่เริ่ม"
- [ ] กด "ถึงแล้ว" ที่อื่นตอนที่มีสถานที่กำลังเที่ยวอยู่ → แอปถามว่า "ปิด {ชื่อ} เป็นเสร็จแล้วไหม"
- [ ] ไม่มีสถานะไหนเปลี่ยนเองเมื่อเวลาผ่านไป

## AC-04 หน้า "ตอนนี้" ครบ 6 สถานะ
เริ่มจากทริปทดสอบที่ยังไม่ได้กดสถานะใดเลย
- [ ] `?now=2026-12-30T12:00` → **ก่อนทริป**: "อีก 1 วันถึงทริป" + "Day 1 ออก 08:00 น. จาก บ้าน (ลำพูน)"
- [ ] `?now=2026-12-31T07:30` → **ก่อนออกเดินทาง**: "ออกจาก บ้าน (ลำพูน) ในอีก" + "30 นาที" + ปุ่ม "นำทางไป วัดพระธาตุลำปางหลวง"
- [ ] `?now=2026-12-31T08:30` → **กำลังเดินทาง**: "กำลังไป วัดพระธาตุลำปางหลวง" + "ถึงประมาณ 09:20 น." + ปุ่ม "ถึง … แล้ว"
- [ ] กด "ถึง … แล้ว" → **อยู่ที่สถานที่**: "ตอนนี้อยู่ที่" + "ต้องออกในอีก" ตัวเลขใหญ่ + "เวลาเที่ยวเหลือ"
- [ ] `?now=2027-01-03T08:00` → ไปที่ Day 4 แล้วกดสถานะ "วัดห้วยปลากั้ง" และ "บ้าน (ลำพูน)" ให้ครบ → **จบวัน**: "จบวันนี้แล้ว" + จำนวนที่เที่ยวแล้ว
- [ ] `?now=2027-01-04T12:00` → **จบทริป**: "จบทริปแล้ว" + สรุปจำนวนที่ไปและที่ข้าม
- [ ] ทุกสถานะ (ยกเว้นจบทริป) เห็นหัวข้อ การ์ดหลัก การ์ด "ต่อไป" และปุ่ม โดยไม่ต้องเลื่อนจอ
- [ ] ย้อนสถานะที่กดไว้ทั้งหมด แล้ว `?now=off`

## AC-05 ปิดแอป 10 นาทีแล้ว countdown ตรง
- [ ] ในแอปบน Home Screen ให้มีตัวนับถอยหลังอยู่ เช่นสถานะก่อนออกเดินทางหรืออยู่ที่สถานที่ แล้วจดตัวเลขไว้
- [ ] ปัดปิดแอปทิ้ง (ไม่ใช่แค่สลับแอป) รอ 10 นาทีตามนาฬิกาจริง แล้วเปิดใหม่
- [ ] ตัวเลขลดลง 10 นาทีพอดี (คลาดได้ไม่เกิน 1 นาทีจากเวลาที่ใช้กดเปิด)
- [ ] ทำซ้ำโดยสลับไปแอปอื่น 10 นาทีแล้วกลับมา ต้องได้ผลเหมือนกัน

## AC-06 เลยเที่ยงคืนยังเป็นวันเดิม
- [ ] `?now=2027-01-01T00:30` → หัวหน้า "ตอนนี้" ยังเป็น **Day 1** · พฤ. 31 ธ.ค. 2569
- [ ] `?now=2027-01-01T03:59` → ยังเป็น Day 1
- [ ] `?now=2027-01-01T04:00` → เปลี่ยนเป็น **Day 2** · ศ. 1 ม.ค. 2570
- [ ] หน้าแผนเที่ยวตอน 00:30 เปิดมาที่ D1 และป้าย "วันนี้" อยู่ที่ D1

## AC-07 เที่ยวเกินแผน
- [ ] `?now=2026-12-31T09:40` → หน้า "ตอนนี้" กด "ถึง วัดพระธาตุลำปางหลวง แล้ว" (ถึงช้าไป 20 นาที)
- [ ] เห็นกล่องส้ม "ถ้าเที่ยวครบเวลา จะช้ากว่าแผน 20 นาที" พร้อมปุ่ม [ออกตามแผน] และ [เลื่อนแผนที่เหลือ +20 นาที]
- [ ] กด **ออกตามแผน** → ตัวนับเวลาเที่ยวเปลี่ยนไปนับถึง 10:50 แผนส่วนที่เหลือไม่ขยับ
- [ ] ย้อนกลับไปที่ "ถึงแล้ว" แล้วกด **เลื่อนแผน** → ดูพรีวิว: พิพิธภัณฑ์ฯ 11:20 → 11:40 และ Lampang Festival ยังเป็น 19:00 (กินเวลาว่าง 20 นาทีพอดี) → ยืนยัน → หน้าแผนเที่ยวเปลี่ยนตามที่เห็นในพรีวิว
- [ ] ลองกด "ปรับเวลา" → "+30 นาที" → พรีวิวต้องเตือนว่าจะถึง Lampang Festival ช้ากว่าเวลาที่ล็อก 10 นาที
- [ ] ย้อนการเลื่อนแผนด้วยปุ่ม "ย้อนกลับ" ใน toast

## AC-08 การเตือน
ในสถานะ "อยู่ที่วัดพระธาตุลำปางหลวง" ที่เริ่มตอน 09:30 (ครบเวลาเที่ยวตอน 11:00 และเวลาออกตามแผนคือ 10:50)
- [ ] `?now=2026-12-31T09:30` → กด "ถึงแล้ว"
- [ ] แผงนักพัฒนา ตั้งเป็น 10:35 → แถบเตือน "อีก 15 นาทีต้องออกไป พิพิธภัณฑ์เซรามิคธนบดี" และมี badge บนแท็บ "ตอนนี้"
- [ ] กดปิดแถบเตือน → แถบหายและไม่กลับมาอีก
- [ ] ตั้งเป็น 10:50 → "ถึงเวลาออกไป พิพิธภัณฑ์เซรามิคธนบดี แล้ว"
- [ ] ตั้งเป็น 11:00 → "ครบเวลาเที่ยวที่ วัดพระธาตุลำปางหลวง แล้ว"
- [ ] **กรณีพลาดการเตือน**: ปิดแอป ตั้งเวลาเป็น 10:57 แล้วเปิดใหม่ → เห็นแถบเตือนพร้อมบอกว่าเลยเวลาออกมา 7 นาที
- [ ] ตอนกำลังเดินทางต้องไม่มีแถบเตือนเลย

## AC-09 โหมดเครื่องบิน
ทำในแอปบน Home Screen
- [ ] ตอนออนไลน์ เปิดแอปค้างไว้ราว 10 วินาที แล้วสลับไปหน้าแผนเที่ยวและหน้าตั้งค่าอย่างละครั้ง
- [ ] เปิดโหมดเครื่องบิน แล้วปัดปิดแอปทิ้ง
- [ ] เปิดแอปใหม่ → ต้องเห็นหน้า "ตอนนี้" และแผนครบ ป้ายด้านขวาบนเป็น "ออฟไลน์"
- [ ] สลับแท็บไปมาได้ทุกแท็บ

- [ ] ปิดโหมดเครื่องบิน → ภายในไม่กี่วินาที ป้ายเปลี่ยนเป็น "รอส่ง …" แล้วเป็น "ออนไลน์"
- [ ] เปิดเว็บบนคอมพิวเตอร์ด้วยบัญชีเดียวกัน → สถานะทั้ง 3 ตรงกับใน iPhone และเวลาที่บันทึกเป็นเวลาที่กดตอนออฟไลน์

## AC-12 ปุ่มนำทางเปิดแอป Google Maps
ต้องติดตั้งแอป Google Maps ใน iPhone และทำในแอปบน Home Screen
- [ ] หน้า "ตอนนี้" กดปุ่มนำทาง → จดว่าเปิด **แอป Google Maps** หรือ **หน้าเว็บ** และเมื่อกลับมา แอป "ไปต่อ" ยังอยู่ที่หน้าเดิมหรือไม่

- [ ] กด **comgooglemaps://** แล้วจดผล (ต้องเปิดแอป Google Maps พร้อมเส้นทางขับรถไปวัดพระธาตุลำปางหลวง)
