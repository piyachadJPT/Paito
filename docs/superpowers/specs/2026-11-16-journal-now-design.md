# ออกแบบใหม่: ธีม "สมุดเดินทาง" + หน้า "ตอนนี้"

วันที่: 16 พ.ย. 2569 · สถานะ: รอผู้ใช้อนุมัติ
Mockup ที่ผู้ใช้เลือก: แบบ B ฉบับเต็ม (`.superpowers/brainstorm/*/content/journal-v2.html`, ไม่อยู่ใน git)

## 1. ทำไม
ผู้ใช้ไม่ชอบ UI ปัจจุบัน: "ธรรมดา ดูเหมือน AI ทำ ไม่มีจุดเด่น ไม่เห็นความตั้งใจ"
ส่วนที่ทำให้จืดที่สุดคือ **สีและพื้นหลัง, ตัวอักษร, ไอคอนและภาพประกอบ**
แอปที่ผู้ใช้ชอบเป็นตัวอย่าง (commute app อีกตัว) มีจุดเด่นคือฉากใหญ่ที่มีชีวิตเปลี่ยนตามเวลา ตัวหนังสือตัวโต และการ์ดลอยอยู่บนฉาก
ผู้ใช้เลือกทิศทาง **สมุดเดินทาง / โปสการ์ด** ใช้ฟอนต์ลายมือ **Mali** เฉพาะหัวข้อ และให้ **ตัดโหมดมืดออก**

## 2. เป้าหมาย / ไม่ใช่เป้าหมาย / สิ่งที่ถือว่าล้มเหลว
**เป้าหมาย**
- เปิดหน้า "ตอนนี้" แล้วรู้สึกเหมือนเปิดสมุดบันทึกทริปของตัวเอง
- ภาพบนโปสการ์ดตรงกับสถานการณ์ตอนนั้น ครอบคลุมเหตุการณ์ให้มากที่สุด (ผู้ใช้ขอเพิ่ม)
- ธีมกลาง (tokens, ฟอนต์, ปุ่ม, แถบเมนู, ไอคอนประเภทสถานที่) เปลี่ยนให้ทุกหน้าใช้ร่วมกันได้

**ไม่ใช่เป้าหมายรอบนี้**
- ยังไม่จัดหน้าแผนเที่ยว ตั้งค่า และ login ใหม่ เพราะผู้ใช้เลือกทำหน้า "ตอนนี้" ก่อน
  แต่หน้าพวกนี้จะได้ tokens/ปุ่ม/แถบเมนูใหม่ไปโดยอัตโนมัติ ต้องไม่พัง
- ไม่เพิ่มข้อมูลหรือฟีเจอร์ ไม่แตะ `lib/schedule` และ data layer
- ไม่มี animation

**ถือว่าล้มเหลว แม้จะทำงานได้**
- ยังดูเป็นการ์ดขาวมุมมนเรียงกันแบบเดิม แค่เปลี่ยนสี
- ภาพประกอบดูเป็น clip-art สำเร็จรูป หรือสไตล์ไม่เข้ากันระหว่างภาพ
- อ่านเวลา/นับถอยหลังยากขึ้นตอนเหลือบมองระหว่างเดินทาง เพราะฟอนต์ลายมือ การเอียง หรือพื้นลาย
- ส่วนที่ 0–4 ของหน้า (SPEC 10.3 / D34) หลุดลงใต้แถบเมนูบนจอ 390×844

## 3. ข้อจำกัด (จาก CLAUDE.md / SPEC ที่ยังใช้อยู่)
- component เขียนเองทั้งหมดใน `src/components/ui/` ห้ามใช้ UI kit
- สถานะต้องมีข้อความกำกับ ห้ามใช้สีอย่างเดียว · ปุ่มแตะได้ ≥ 44px · ข้อความต้องมีคอนทราสต์ ≥ 4.5:1 บนพื้นจริง (รวมพื้นกระดาษและภาพ)
- ตัวเลขนับถอยหลังใช้ `ui-rounded` + `tabular-nums` · ข้อความเวลาและการเตือนต้องตรงตามสเปก
- ทุกอย่างต้องใช้ได้ตอน offline ห้ามมีรูปหรือฟอนต์จาก origin อื่นตอน runtime
- ค่าที่ขึ้นกับเวลา render ฝั่ง client เท่านั้น · "ตอนนี้" มาจาก `lib/clock`
- `lib/` ต้อง pure เท่านั้น

## 5. ธีมกลาง
**กระดาษ**
- พื้นหลังของทุกหน้าเป็นกระดาษสีอุ่น (ประมาณ `#EFE7D6`) มีเนื้อ noise จาง ๆ และเส้นบรรทัดห่าง ~30px
- หน้า "ตอนนี้" มีเส้นขอบสมุดแนวตั้งสีแดงจางด้านซ้าย
- ลายพื้นต้องจางพอที่ข้อความทุกสีผ่านคอนทราสต์
- texture ทำด้วย CSS/SVG inline เท่านั้น ไม่มีไฟล์รูป

**สี**
- ปรับ token ใน `globals.css` ให้เข้ากับกระดาษ: การ์ด/โปสการ์ด `#FFFDF7`, หมึกน้ำเงิน `#12608F` เป็นสีหลัก, หมึกแดงตราประทับ (ประมาณ `#C2562F`)
- ลบบล็อก dark ทั้งหมด
- `themeColor` ใน `layout.tsx` และสีใน `manifest.ts` เปลี่ยนเป็นสีกระดาษ เหลือค่าเดียว

**ฟอนต์**
- Mali น้ำหนัก 500/600/700 โหลดผ่าน `next/font/local` จากไฟล์ใน repo พร้อมไฟล์ไลเซนส์ OFL
- ไฟล์จะไปอยู่ใต้ `/_next/static/media` ซึ่ง SW precache อยู่แล้ว (D38) ต้องตรวจว่า offline ได้จริง
- ประกาศเป็น `--font-hand`

**ปุ่ม**
- เปลี่ยนเป็นแบบ "กระดาษกดได้": มีเงาทึบด้านล่าง 3px
  - primary: พื้นหมึกน้ำเงิน
  - secondary: พื้นกระดาษ ขอบหมึกจาง
- ตอนกด: เลื่อนลง 2px และเงาหายไป (เปลี่ยนสถานะทันที ไม่มี transition)
- ต้องมีครบทุกสถานะ: ปกติ กด โฟกัส ปิดใช้งาน

**แถบเมนู**
- ยังเป็นแถบลอย blur ตามเดิม แต่พื้นเป็นกระดาษ
- ไอคอนวาดมือ: ตอนนี้ = นาฬิกา, แผนเที่ยว = สมุด, ตั้งค่า = แถบปรับ
- แท็บที่เลือกอยู่มีขีดหมึกใต้คำแทนพื้นทึบ
- จุดเตือนสีส้มยังอยู่ และยังมีข้อความ sr-only กำกับ

**ไอคอนวาดมือ**
- ชุดเดียว เขียนไว้ใน `src/components/ui/icons/`
- เส้น 2px ปลายมน ลากเส้นไม่ตรงเป๊ะ ใช้ `currentColor`
- ชุดขั้นต่ำ:
  - ไอคอนประเภทสถานที่: เที่ยว / กิน / พัก / ที่พัก
  - ไอคอนบนปุ่ม: นำทาง, เสร็จ, ปรับเวลา, ข้าม, ถึงแล้ว, ปฏิทิน, ปิด
  - ไอคอนอื่น: เตือน, ล็อก, รถ, โทร, สมุดข้อมูล และไอคอน 3 แท็บ
- `StopTypeIcon` ใน `plan/stop-visuals.tsx` เปลี่ยนไปใช้ไอคอนชุดนี้ด้วย (หน้าแผนเที่ยวจะได้ไอคอนใหม่ไปด้วย)

## 6. หน้า "ตอนนี้"
ลำดับยังเป็นไปตาม D34 เปลี่ยนเฉพาะหน้าตา

**0. หัวหน้า**
- บรรทัดเล็ก Mali: "วันแรก · พ. 31 ธ.ค. 2569" ใช้ "วันแรก / วันที่ 2 / … / วันสุดท้าย" + วันที่จากตาราง D27 · สถานะ sync อยู่ขวา
- บรรทัดใหญ่ Mali ~30px คือชื่อเส้นทางของวัน เอาส่วนของ `day.title` ก่อน " · " ตัวแรกมาแสดง
- ถ้าไม่มีวัน (ก่อน/หลังทริป) ใช้ชื่อทริปแทน

**1. การเตือน และกล่อง "ช้ากว่าแผน"**
- ทำเป็น "กระดาษโน้ตแปะ" สีส้มอ่อน มีเทปที่มุม เอียงไม่เกิน 0.5°
- ข้อความและปุ่มปิดตามเดิม

**2. การ์ดหลัก = โปสการ์ด**
- พื้นขาวนวล เงา เอียง −1.2° มีเทปตรงกลางด้านบน
- ภาพประกอบอยู่ด้านบน มีตราประทับวงกลมทับมุมล่างซ้าย และแสตมป์ที่มุมขวาบน
- ข้อความตาม state เหมือนเดิมทุกคำ
- ตัวเลขใหญ่ใช้สีหมึกน้ำเงิน ถ้าเลยเวลาเปลี่ยนเป็นส้ม (warning-ink)

| state | ตราประทับ | แสตมป์ |
|---|---|---|
| at_stop | ชื่อที่นี่ + "ถึง HH:MM" | "ออก HH:MM" |
| pre_departure | ชื่อจุดออก | "ออก HH:MM" |
| in_transit | ชื่อที่หมาย | "ถึง ~HH:MM" |
| day_done | ชื่อที่พัก | "พรุ่งนี้ HH:MM" |
| before_trip | — | "อีก N วัน" |
| after_trip | — | "จบทริป" |

- **ความสูงภาพ:** ปกติ ~150px · มีการเตือนหรือกล่องช้ากว่าแผน ลดเหลือ ~96px · มีทั้งสองอย่าง ~72px
  เพื่อให้ส่วน 0–4 ยังอยู่เหนือแถบเมนูบนจอ 390×844 (ตัวเลขเป็นค่าตั้งต้น builder ปรับได้ แต่ต้องผ่านเงื่อนไขนี้)

**3. "ต่อไป"**
- เป็นแถบกระดาษแบบต้นขั้วตั๋ว ขอบซ้ายเป็นรอยปรุ
- ข้อมูลเดิม: ไอคอนประเภทวาดมือ, ชื่อ, เวลาขับ, เวลาถึง, ล็อก

**4. ปุ่ม**
- ข้อความและพฤติกรรมเดิมทุกปุ่ม ใช้ปุ่มแบบกระดาษกดได้ + ไอคอนวาดมือ

**5. ความคืบหน้า**
- เส้นถนนประวาดมือ มีหมุดของที่ไปแล้วเป็นวงหมึกแดง "✓" ที่กำลังอยู่เป็นหมุดน้ำเงินมีวง ที่ข้ามเป็นวงประ
- มีข้อความ "เที่ยวแล้ว x จาก y ที่ · ข้าม n" เหมือนเดิม
- วางบนกระดาษตรง ๆ ไม่มีกรอบการ์ด

**6. ข้อมูลสำคัญ**
- เป็นแถบป้ายแบบแถบดัชนีสมุด (index tab) ที่กดได้ · sheet ข้างในเหมือนเดิม

**7. แผนของวันนี้**
- หัวข้อใช้ Mali · รายการเป็นเส้นประแนวตั้ง มีไอคอนประเภทวาดมือเป็นหมุด
- เสร็จแล้ว: ชื่อขีดฆ่าด้วยหมึกแดง + ตราประทับเล็ก "เสร็จ HH:MM" จาก `completed_at` (ใช้ `started_at` สำหรับจุดออก)
  ตราประทับต้องอ่านได้ทั้งคำ และต้องมีข้อความสถานะ (เช่น sr-only หรือตัวคำว่า "เสร็จ") ไม่ใช้สีอย่างเดียว
- กำลังเที่ยว: ตัวหนา + ป้าย "อยู่ที่นี่"
- ข้าม: ขีดฆ่าสีเทา + ป้าย "ข้าม"
- ยังไม่เริ่ม: เวลาตามแผน
- ปุ่ม "ดูทั้งหมด" ยังอยู่

**อื่น ๆ**
- Skeleton: บล็อกโปสการ์ดและบรรทัดสีกระดาษเข้ม
- ไม่มีทริป: ใช้โปสการ์ดเปล่ากับภาพ `empty` + ข้อความเดิม + ปุ่มไปตั้งค่า
- staleInProgress (D9): เป็นกระดาษโน้ตแบบเดียวกับข้อ 1

## 7. ภาพบนโปสการ์ด (ส่วนที่ผู้ใช้ขอให้ครอบคลุมมากขึ้น)
ภาพ = **ท้องฟ้าตามช่วงเวลา** + **ฉากพื้นภูเขาภาคเหนือ** + **ตัวเรื่อง** ซ้อนกันเป็น SVG inline วาดในสไตล์เดียวกัน (เส้นหมึก 2px ปลายมน + สีพื้นแบบสีน้ำแบน) ไม่มีไฟล์รูป

**ช่วงเวลา (6 ช่วง)** ตามชั่วโมงท้องถิ่นของทริป
| ช่วง | ชั่วโมง | ท้องฟ้า |
|---|---|---|
| ฟ้าสาง | 05–07 | ฟ้าชมพูม่วง ดวงอาทิตย์ครึ่งดวง หมอก |
| เช้า | 07–10 | ฟ้าสว่างอมส้ม |
| กลางวัน | 10–16 | ฟ้าใส ดวงอาทิตย์สูง |
| เย็น | 16–19 | ฟ้าส้มแดง ดวงอาทิตย์ต่ำ |
| ค่ำ | 19–23 | ฟ้าน้ำเงินเข้ม จันทร์ ดาว |
| ดึก | 23–05 | ฟ้าเกือบดำ ดาวเยอะ |

ช่วงเวลาเหล่านี้ใช้แทน `tintFor()` เดิมด้วย

**ตัวเรื่อง** เลือกจาก state → ประเภทสถานที่ → คำในชื่อสถานที่ (ไม่สนตัวพิมพ์ใหญ่/เล็ก) → ช่วงเวลา
| เหตุการณ์ | เงื่อนไข | ตัวเรื่อง |
|---|---|---|
| วัด | sight ชื่อมี "วัด", "พระธาตุ", "temple" | เจดีย์ทอง |
| จุดชมวิว / ภูเขา | "ดอย", "ภู", "จุดชมวิว", "ม่อน", "viewpoint" | ยอดดอย + ธงเล็ก |
| น้ำตก / ธรรมชาติน้ำ | "น้ำตก", "ทะเลสาบ", "บ่อน้ำร้อน", "hot spring" | น้ำตก / ไอน้ำ |
| พิพิธภัณฑ์ / ศิลปะ | "พิพิธภัณฑ์", "หอศิลป์", "museum", "art" | อาคารมีเสา + กรอบรูป |
| ตลาด / ถนนคนเดิน | "ตลาด", "ถนนคนเดิน", "market" | แผงร้านมีโคม |
| ไร่ / สวน | "ไร่", "สวน", "ฟาร์ม", "farm" | แถวต้นชา/ดอกไม้ |
| เที่ยวทั่วไป | sight อื่น ๆ | กล้องถ่ายรูป + หมุด |
| อาหารเช้า | food ช่วงฟ้าสาง/เช้า | ชามโจ๊ก + ปาท่องโก๋ + แก้วกาแฟ |
| อาหารกลางวัน | food กลางวัน | ข้าวซอย |
| อาหารเย็น | food เย็น/ค่ำ | หม้อหมูกระทะ/ชุดขันโตก |
| มื้อดึก | food ดึก | ชามก๋วยเตี๋ยวใต้โคมไฟ |
| คาเฟ่ | food/rest ชื่อมี "คาเฟ่", "กาแฟ", "coffee", "cafe" | แก้วกาแฟมีไอ |
| แวะพัก | rest อื่น ๆ | ปั๊ม/ศาลาริมทาง |
| อยู่ที่พัก | lodging (at_stop) | บ้านพักเปิดไฟ |
| เตรียมออก | pre_departure | รถจอดหน้าบ้านพัก + กระเป๋า |
| กำลังขับ | in_transit | รถบนถนนคดเคี้ยวมีเส้นประ |
| ใกล้ถึง | in_transit + `probablyArrived` | รถหยุดข้างหมุดธง |
| จบวัน | day_done | บ้านพักกลางคืน (ใช้ฟ้าค่ำเสมอ) |
| ก่อนทริป | before_trip | กระเป๋าเดินทาง + ปฏิทิน |
| จบทริป | after_trip | กองรูปถ่าย + รถกลับบ้าน |
| ไม่มีทริป | NoTrip | โปสการ์ดเปล่า + ดินสอ |

**ของแต่งเสริม** ซ้อนบนตัวเรื่อง เพื่อบอกเหตุการณ์ได้ครอบคลุมขึ้น
- **คืนส่งท้ายปี:** 31 ธ.ค. ช่วงค่ำ/ดึก → พลุบนฟ้า
- **วันขึ้นปีใหม่:** 1 ม.ค. ช่วงฟ้าสาง/เช้า → ป้าย "สวัสดีปีใหม่" แบบธงราว
- **เลยเวลาออก / ช้ากว่าแผน:** สติกเกอร์นาฬิกาปลุกเล็กที่มุมภาพ (ข้อความเตือนยังอยู่ในการ์ดตามเดิม ภาพเป็นแค่ของแต่ง)

**การเลือกภาพ**
- เป็น pure function ใน `src/lib/scene/`: `pickScene({ state kind, stop, flags }, localHour, localDate) → { sky, subject, extras[] }`
- รับเวลาเป็นพารามิเตอร์ ไม่เรียก `Date.now()`
- มี unit test ครอบคลุมทุกแถวในตารางและทุกขอบช่วงเวลา
- ตัววาดอยู่ใน `src/components/now/scene/` (หรือ `ui/` ถ้าใช้ร่วมกับหน้าอื่น)
- ภาพทั้งหมดเป็น `aria-hidden` เพราะข้อมูลทุกอย่างมีเป็นข้อความอยู่แล้ว
